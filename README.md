# Решения задач курса [Задачник на Python](https://stepik.org/a/294917) на Stepik

В репозитории собраны все 300 задач курса. В файле задачи есть условие и решение, которое проходит проверку на Stepik. Репозиторий нужен, чтобы после решения задачи можно было сравнить свой код с вариантом автора курса.

## Как пользоваться

1. Сначала решите задачу сами и отправьте решение на Stepik.
2. Найдите файл задачи. Он лежит в папке модуля, внутри неё в папке урока и называется `step_NN.py`, где `NN` означает номер шага в уроке. Ссылки на все файлы есть в содержании ниже.
3. Сравните своё решение с решением из файла.

Если задача не получается, не открывайте решение сразу. Перечитайте справку в начале урока, откройте подсказку под условием на Stepik, запустите программу на своих данных и выведите через `print()` переменные, в которых сомневаетесь. Подсмотренное решение почти ничему не учит.

## Как запустить решение

Нужен Python 3.10 или новее, сторонние библиотеки не нужны. Решения читают входные данные через `input()`, как на Stepik. Например, так запускается первая задача.

```bash
python 02_introduction/01_print_output/step_02.py
```

или

```bash
python3 02_introduction/01_print_output/step_02.py
```

После запуска введите данные с клавиатуры, как описано в условии в начале файла.
